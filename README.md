# Car Rental App 🚗

A web application for browsing and renting cars. Users can view a catalog of cars, filter them by different criteria, and open detailed pages for each car with full information and a booking form.

## Features
- Car catalog with filtering
- Detailed car pages
- Booking form with validation
- Responsive design
- Form validation (no backend submission yet)

## Tech Stack
- React
- Next.js
- JavaScript / TypeScript
- REST API
- Zustand

## Purpose
This project was built to practice frontend development, working with dynamic data, filtering systems, and form handling.

## Getting Started

1. Clone the repository:
git clone https://github.com/MalskoSo1/rental-car.git

2. Install dependencies:
npm install

3. Run the project:
npm run dev
